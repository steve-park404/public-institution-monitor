# V8.23 유사기관 통합 모니터링

기존 모니터링 프로그램의 검색/매칭/텔레그램 로직은 그대로 사용합니다.

## 추가되는 것
사용자가 직접 확인한 `게시판URL`이 입력된 유사기관만 기존 기관목록 Excel에 병합합니다.

현재 제공된 추가 Excel 기준:
- 유사기관 후보: 190개
- 게시판URL 입력 완료: 160개
- 게시판URL 미입력: 30개

따라서 현재는 최대 약 355 + 160 = 515개 기관을 대상으로 검색할 수 있습니다.
실제 최종 대상 수는 기존 355개와 기관명이 중복되는 항목에 따라 달라집니다.

## GitHub 적용
이 압축파일의 파일을 기존 저장소 루트에 그대로 넣습니다.

- `merge_extra_targets.py`
- `유사기관_추가모니터링_후보목록_URL입력완료 (2).xlsx`
- `.github/workflows/V8.23_유사기관_통합모니터링.yml`

기존 `monitor.py`는 교체하지 않습니다.

Workflow는:
1. 기존 기관 Excel 확인
2. 유사기관 Excel의 수동 게시판 URL 병합
3. 통합 기관 수 확인
4. 기존 `monitor.py` 실행
5. 결과/상태 파일 커밋

순서로 동작합니다.

## 향후 URL 추가
사용자가 유사기관 Excel의 `게시판URL` 열에 URL을 추가하고 커밋하면,
다음 실행 때 자동으로 모니터링 대상에 편입됩니다.
