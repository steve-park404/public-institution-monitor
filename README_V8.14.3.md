# 티끌 알림봇 V8.14.3

V8.14.2를 기반으로 **게시판 발견률 개선**에 집중한 버전입니다.

## 핵심 변경
- 별도 `board_cache.json` 도입: 한 번 검증된 게시판 URL을 기관별로 영구 저장
- 캐시 게시판 우선 사용: 다음 실행부터 홈페이지 재탐색을 줄임
- 1차 홈페이지 링크 탐색 실패 시 2차 탐색
  - `sitemap.xml`
  - `robots.txt` 및 Sitemap 지시 URL
  - 공공기관에서 자주 쓰이는 대표 게시판 경로
- 게시판 후보 검증은 기존과 동일하게 실제 게시물 링크가 있는지 확인
- 홈페이지/게시판 요청 재시도 강화 및 브라우저형 User-Agent 재시도
- `diagnostics.json`에 `board_cache_total`, `board_cache_verified` 추가
- V8.14.2의 기능 유지
  - 355기관
  - 공기업·준정부기관 / 기타공공기관 유형별 요약
  - 최근 30일
  - 설문조사 / 시민참여 / 국민참여
  - 제목의 공모전 제외
  - 실제 게시물 검증
  - Telegram 일 최대 20건
  - pending / sent URL 중복방지
  - 기존 상태 승계
  - GitHub Actions 동시 실행 방지 및 충돌 자동 처리

## 새 파일
`board_cache.json`은 실행 후 자동 생성됩니다. 직접 만들 필요 없습니다.

## 운영 목표
이번 버전의 우선 목표는 키워드 매칭 수를 늘리는 것이 아니라 **게시판 확인율을 높이는 것**입니다. 특히 V8.14.2에서 확인율이 46.2%였던 공기업·준정부기관 그룹의 게시판 확보율 개선 여부를 확인합니다.
