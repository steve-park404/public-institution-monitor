기관 후보 발굴 V1.2

핵심 목적
- 단순히 ALIO 화면의 문자열을 기관으로 오인하지 않고 실제 공공기관 후보만 보수적으로 추출
- 서비스/SNS/포털/시스템/기관유형 문자열/숫자 등의 오탐 제거
- 지부·지역본부·사업소·교육원 등 ALIO가 부모기관을 명시하는 경우 부모기관으로 통합
- 기존 355기관은 후보에서 제외
- ALIO 설문정보는 후보를 새로 만드는 용도가 아니라 참여기회 신호 점수화 용도로만 사용

V1.1에서 확인된 대표 오탐
- 기관 홈페이지
- 인스타그램
- 페이스북
- 4787
- KIPRO통합접수시스템
- Q-net(자격정보)
- TAAS(교통사고분석시스템)
- 공공누리
- 공기업(시장형)
- 기타공공기관
- 중소벤처기업진흥공단 지역본부/지부 등 부속조직

V1.2 변경
1. 기관유형 정확 일치 검증
2. 주소 + 기관유형 + DOM 기관카드 교차검증
3. 서비스/SNS/포털/시스템/메뉴명 차단
4. 부모기관/기관유형 표기 분리 및 부모기관 통합
5. 기존 355기관 중복 제거 후 신규 후보만 출력
6. 설문정보는 기존 후보와 매칭되는 경우에만 점수 반영
7. 결과 CSV + 요약 JSON + 진단 JSON 자동 생성
8. GitHub Actions Artifact 30일 보관 + main 자동 커밋
9. 결과 품질검증 실패 시 workflow를 성공 처리하지 않음

운영
- 매주 일요일 10:20 KST 실행(cron 20 1 * * 0)
- workflow_dispatch로 수동 실행 가능
