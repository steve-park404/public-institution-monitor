# V8.8 — 355개 기관 홈페이지 기반 참여정보 모니터링

- 대상: **355개 기관을 1행 1기관으로 관리**
- 키워드: `설문조사`, `시민참여`, `국민참여`
- `공모전`은 키워드에서 완전히 제외
- 검색 범위: 게시물 **제목 + 본문**
- 알림: Telegram
- 실행: GitHub Actions, 하루 1회
- PC 상시 실행 불필요

## 구조

`355기관 → 공식 홈페이지 → 공지/알림/소식 게시판 탐색 → 최근 게시물 상세페이지 → 제목/본문 키워드 검색 → Telegram`

기존에 확인된 게시판 URL은 `공지게시판URL`에 seed로 넣고, 없는 기관은 홈페이지에서 자동 탐색합니다.
자동 탐색으로 찾은 게시판은 `state.json`의 `boards`에 저장하여 다음 실행부터 매번 홈페이지 전체를 다시 탐색하지 않도록 했습니다.

## 주의

원본 `url.xlsx`의 URL이 비어 있는 기관은 기존 작업 산출물에서 홈페이지 URL을 복원했습니다.
복원되지 않은 기관은 `URL상태=홈페이지 URL 확인 필요`로 표시되어 있으며, 해당 기관은 모니터링 시 자동으로 건너뛸 수 있습니다.
