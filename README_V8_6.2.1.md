# V8.6.2.1 — 오류 수정판

V8.6.2 실행 중 BeautifulSoup의 일부 malformed HTML에서 `attrs=None`이 발생해 전체 작업이 중단되는 문제를 수정했습니다.

주요 수정:
- HTML 태그의 `attrs=None` 안전 처리
- `<a>` 태그의 비정상 속성 안전 처리
- 개별 기관 처리 예외 격리: 한 사이트 오류가 전체 작업을 중단하지 않음
- 기존 100개 대상과 4개 키워드 유지
- 기존 Telegram Secrets 그대로 사용
- 기존 state.json과 호환

키워드는 다음 4개만 사용합니다:
설문조사
시민참여
국민참여
공모전
