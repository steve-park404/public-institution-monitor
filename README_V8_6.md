# V8.6 100개 공지사항 자동검색 — 4개 키워드 수정본

## 검색 키워드
이 프로젝트에서 검색하는 키워드는 **아래 4개뿐입니다.**

1. 설문조사
2. 시민참여
3. 국민참여
4. 공모전

`monitor.py`에서 4개 키워드를 코드로 고정했으므로 `keywords.txt`에 다른 단어가 추가되어도 검색 대상에 포함되지 않습니다.

## 검색 범위
- 사전 검증된 기관별 게시판
- 게시물 제목
- 제목에 키워드가 없으면 게시물 상세페이지 본문

## 대상
- `monitor_targets.xlsx`
- 총 100개 게시판

## 실행
- GitHub Actions 수동 실행 가능
- 매일 UTC 00:10 = 한국시간 09:10 자동 실행
- 동시 처리 12개
- 사이트별 timeout 15초
- HTTP 재시도 2회
- 전체 실행 상한 600초

## Telegram
새로운 키워드 매칭만 알림합니다.
첫 실행에서는 기존 게시물을 state에 등록하여 기존 게시물 알림 폭탄을 방지합니다.

## 적용 방법
저장소 최상위에 다음 파일을 덮어씁니다.

- `monitor.py`
- `monitor_targets.xlsx`
- `keywords.txt`
- `requirements.txt`
- `.github/workflows/v8_6_monitor.yml`

기존 `state.json`, `monitor_log.json`은 유지합니다.

## 중요
이번 버전은 검색 목적을 명확히 하기 위해 검색 키워드를 4개로 고정했습니다.
안전, 산업안전, 점검, 교육, 시설, 선박 등 다른 키워드는 검색하지 않습니다.
