# V8.3 공지사항 후보 자동검증

V8.2 검색엔진이 안정화된 다음 단계입니다.

## 목적
기존 V7.2에서 발견했던 게시판 후보 중 `공지사항`, `공지`, `알림마당`, `새소식`, `기관소식` 등 공지성 게시판만 다시 검증합니다.

## 중요한 원칙
- V8.2의 `monitor_targets.xlsx`는 수정하지 않습니다.
- V8.3은 후보 검증만 수행합니다.
- 실제 게시물 상세 페이지까지 확인합니다.
- 목록 제목과 상세 본문이 일치하는지 확인합니다.
- 자동확정 기준을 엄격하게 적용합니다.

## 결과
- A-최종확정: 바로 V8.2 모니터링 대상으로 추가 가능
- B-자동화가능: 소폭 보완 후 추가 가능
- C-추가분석: 수동 확인 필요
- D-제외: 현재 자동화 대상에서 제외

## 사용법
1. 이 폴더의 파일을 GitHub 저장소 루트에 업로드합니다.
2. `.github/workflows/v8_3_notice_validation.yml`이 생성되어야 합니다.
3. Actions → `V8.3 공지사항 후보 자동검증` → Run workflow
4. 완료 후 `v8_3_notice_validation.xlsx`의 A/B 결과를 확인합니다.

V8.3 결과가 안정적이면 A와 B 중 실제 공지사항 게시판만 선별하여 V8.2의 `monitor_targets.xlsx`를 단계적으로 확대합니다.
