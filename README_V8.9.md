# V8.9 — 355기관 게시판 고정형 모니터링

## 핵심
- 대상은 **355개 기관(1행=1기관)**.
- 키워드: `설문조사`, `시민참여`, `국민참여`
- `공모전` 제목은 제외.
- 제목 우선 검색 + 본문은 노이즈 제거 후 엄격 검색.
- Telegram 알림.
- GitHub Actions 하루 1회.
- 최초 실행에서 게시판을 찾으면 `state.json`에 저장하여 다음 실행부터 고정 사용.

## 운영 구조
1. `monitor_targets.xlsx`에서 355기관을 읽음.
2. `공지게시판URL`이 있으면 그것을 우선 사용.
3. 없으면 홈페이지에서 공지/알림/소식 계열 게시판을 1회 탐색.
4. 발견한 게시판을 `state.json`의 `boards`에 저장.
5. 이후에는 저장된 게시판의 최근 게시물만 확인.
6. 상세페이지 제목에서 3개 키워드를 우선 검색.
7. 제목에 없을 때만 본문을 엄격하게 검색.
8. 새 매칭만 Telegram으로 전송.

## V8.8 대비 개선
- XML parser 경고 억제.
- 본문 단순 substring 매칭 완화.
- 메뉴/공통영역 제거.
- 본문 매칭에 최소 길이 및 문맥 조건 적용.
- 게시판 URL 캐시.
- 355기관 상태를 `monitor_targets.xlsx`에서 관리.
