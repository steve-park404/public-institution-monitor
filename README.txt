# 기관 후보 발굴 프로그램 V1

목적:
- 기존 355개 기관을 기준으로 신규 기관 후보를 자동 발굴
- ALIO Plus 기관정보를 수집
- ALIO Plus 설문정보를 참여정보 발생 신호로 활용
- 기존 355개와 중복 제거
- `기관후보_발굴결과.csv` 생성

## 출력 주요 컬럼
- 기관명
- 기관유형
- 홈페이지URL(원천 데이터에서 확보 가능한 경우)
- 기존355
- 후보출처
- 출처URL
- 설문/참여건수
- 참여정보키워드
- 후보점수
- 추천등급(A/B/C)

## 중요한 운영 원칙
이 프로그램은 후보를 자동으로 '모니터링 대상'으로 확정하지 않습니다.
`기관후보_발굴결과.csv` -> 검토/승인 -> `기관목록_확장.csv` 순서로 편입합니다.

## 기존 모니터링과의 연동
최종적으로 monitor.py가 읽는 기관 목록 파일을
`기관목록_확장.csv` 하나로 통일합니다.

즉:
기관후보 발굴 -> 승인된 후보 병합 -> 기관목록_확장.csv -> V8.14.x monitor.py

후보 발굴 프로그램과 모니터링 프로그램은 서로 독립적으로 유지하는 것을 권장합니다.
