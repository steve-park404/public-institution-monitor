# V8.14.20 BODY 매칭 오탐 차단

V8.14.20의 V8.14.19 기반 구조를 355기관/수동 게시판 URL/게시판 캐시/Telegram/상태·중복관리 구조를 유지하고, **게시물 판별과 BODY 매칭만 강화**한 버전입니다.

## 이번 버전의 핵심 수정
- 대표 홈페이지 `/index.do`, `/index.jsp`, `/main.do`, `/main.jsp` 및 변형 경로를 상세 게시물로 오인하지 않음
- 기관명/사이트명과 동일한 짧은 제목을 BODY 매칭에서 차단
- `국민참여`/`시민참여`는 단순 메뉴·푸터 문구가 아니라 실제 참여행동 신호가 있어야 통과
- `설문조사`는 설문 참여/응답/기간/대상/방법/링크 등 실제 행동 증거가 있어야 통과
- 당첨자/결과발표/조사결과/선정결과 등 결과성 게시물은 신규 참여기회로 알리지 않음
- `공모전` 제목 제외 유지
- 최근 30일, 실제 상세페이지, 기존 중복방지/발송대기열/Telegram 구조 유지
- **게시판 발견 구조는 변경하지 않음**

## 목표
이번 버전은 검색 범위를 넓히는 버전이 아니라, 현재 V8.14 계열에서 확인된 BODY 오탐을 줄이는 정밀도 개선 버전입니다.


## V8.14.20 게시판 URL 최신화
- 사용자 제공 `기관별_상태(3).csv`의 `기관명`-`게시판URL`을 기준으로 게시판 URL만 최신화했습니다.
- `monitor.py`와 `.github/workflows/V8.14.20.yml`의 로직은 변경하지 않았습니다.
- 게시판 URL 입력값: 348개 / 355개
