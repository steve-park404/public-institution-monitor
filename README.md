# V8.14.18

V8.14.17의 검색/검증 로직을 그대로 유지하고, 사용자가 직접 확인한 `기관별_상태.csv`의 `게시판URL`만 입력값으로 추가합니다.

핵심 변경은 2개뿐입니다.
1. `게시판URL` 수동 입력값을 355기관 원본 목록에 병합
2. 수동 입력 URL을 기존 board_cache/state보다 우선 사용

검색 조건, 실제 게시물 검증, 최근 30일, 제목/본문 키워드, 공모전 제외, 중복 방지, Telegram 발송 등은 기존 로직을 유지합니다.

주의:
- `monitor_targets.xlsx` 또는 기존 대상 파일은 저장소에 이미 있어야 합니다.
- `board_cache.json`을 새로 생성하거나 초기화하지 않습니다.
- 기존 `board_cache.json`이 있으면 유지하면서 수동 URL을 우선 검증합니다.
