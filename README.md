# V8.14.19

V8.14.18의 수동 게시판 URL과 기존 탐색/검증 구조를 유지하면서 BODY 키워드 오탐을 줄인 버전입니다.

## 핵심 수정
- `국민참여`/`시민참여` 단어가 메뉴·푸터·일반 안내문에 있는 것만으로 BODY 매칭하지 않음
- 설문/조사/의견/응답/참여기간/참여방법 등 실제 행동 신호가 주변에 있어야 통과
- 홈페이지 `index.do`, `index.jsp`, `main.do`, `main.jsp`를 상세 게시물로 오인하지 않음
- `사학연금 | ...`처럼 사이트 공통 제목을 게시물 제목으로 잡는 짧은 제목 오탐 차단
- 게시판 URL, 최근 30일, 실제 상세페이지, 제목/본문 키워드, 공모전 제외, 중복 방지, Telegram 구조는 유지

이번 버전은 '검색 범위를 넓히는' 버전이 아니라 '잘못 잡힌 결과를 줄이는' 버전입니다.
