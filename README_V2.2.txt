# 티끌 알림봇 V2.2
V2.0에서 확인된 오탐을 줄이고 '실제 모집 중인 보상형 참여기회'만 Telegram에 보내는 버전.

## V2.0 분석에서 확인된 오탐
- 설문조사/기프티콘 가이드
- 설문조사 대행/서비스 페이지
- 오래된 블로그/후기
- FGI/UX 관련 정보성 글
- 모집 종료된 과거 공고
- 이벤트/경품 사이트 자체 페이지
- 리서치 에이전시 소개 페이지

## V2.2 변경
1. 제목의 가이드/후기/리뷰/정리/소개/대행/에이전시/플랫폼 등을 제외
2. 실제 '모집/참여자/참가자' 신호가 없으면 제외
3. 오래된 페이지를 제외
4. 공모전/채용/입찰 등 제외
5. 보상정보가 명시된 후보를 Telegram 우선
6. Telegram은 하루 최대 10건으로 축소
7. 제외 결과도 CSV로 저장해 필터 품질을 검증할 수 있게 함
8. 유형(설문/패널/인터뷰/FGI/사용성테스트 등)을 표시

기존 V8.14.17 355개 기관 감시와 별도로 운영합니다.


## V2.2 사용자 맞춤 변경
- FGI/좌담회/집단면접 검색어 제거
- FGI/좌담회 제목 및 본문 판정 제외
- 사용성 테스트, 일반 인터뷰, 설문, 패널 등은 계속 탐색
