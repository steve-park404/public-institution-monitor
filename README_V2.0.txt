# 티끌 알림봇 V2.0

## 핵심 변화
V1.x의 '신규 기관 찾기' 방식에서 벗어나 인터넷 검색 결과에서 실제 참여기회를 직접 찾습니다.

### 검색 대상
- 설문조사 / 온라인 설문
- 패널 모집
- 인터뷰 / FGI / 좌담회
- 사용성 테스트
- 제품·서비스 테스트
- 베타테스터
- 모니터단
- 소비자 조사
- 시민참여 / 국민참여 / 의견수렴

### 자동 처리
1. 웹 검색
2. URL 중복 제거
3. 실제 페이지 내용 수집
4. 보상정보 추출
5. 마감정보 추출
6. 참여기회 점수 계산
7. 공모전/채용/입찰 등 제외
8. 이미 본 URL+제목 중복 제거
9. 상위 신규 후보 Telegram 전송
10. 결과 CSV/JSON 저장

## GitHub Secrets
Repository > Settings > Secrets and variables > Actions에 다음 2개를 추가합니다.

- TELEGRAM_BOT_TOKEN
- TELEGRAM_CHAT_ID

기존 알림봇에서 사용 중인 동일한 Telegram 값을 사용하면 됩니다.

## 일정
매일 09:20 KST.
GitHub Actions의 schedule은 UTC 기준으로 지정했습니다. 현재 설정은 00:20 UTC = 09:20 KST입니다.
GitHub는 scheduled workflow를 default branch에서 실행하며, 부하가 높은 정각을 피하는 것을 권장합니다.

## 주의
검색엔진 색인에 없는 페이지는 발견할 수 없습니다.
따라서 V2는 '웹 전체를 완벽하게 크롤링'하는 시스템이 아니라 검색엔진이 발견할 수 있는 공개 페이지를 폭넓게 탐색하는 시스템입니다.
