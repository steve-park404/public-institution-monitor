# V8.6.3 — 100개 본문 오탐 개선

## 목적
기존 V8.6.2.1의 게시글 본문 검색에서 메뉴/푸터/관련글 등 공통 영역이 본문으로 잡혀 발생하는 오탐을 줄입니다.

## 키워드
아래 4개만 사용합니다.
- 설문조사
- 시민참여
- 국민참여
- 공모전

## 주요 개선
1. 리스트 페이지를 더 엄격하게 제외
2. 숫자만 있는 제목(예: 10) 제외
3. 상세 게시글 URL을 우선 선택
4. header/footer/nav/aside/script/style/form 및 메뉴·관련글·검색·댓글 등의 영역 제거
5. article/main/content/view/detail/body 계열 영역을 우선 본문으로 사용
6. 본문 영역에서만 4개 키워드 검색
7. 기관별 예외처리로 한 사이트 오류가 전체 실행을 중단하지 않도록 함
8. 기존 state.json 형식(list/dict) 호환
9. Telegram 유지
10. 100개 대상 유지

## 실행
GitHub → Actions → `V8.6.3 100개 본문 오탐개선` → Run workflow
